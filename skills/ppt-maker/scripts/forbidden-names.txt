# forbidden-names.txt
#
# 生成出来的 PPT 里不允许出现的人名，一行一个（UTF-8，无 BOM）。
# 出现在页眉、署名、正文、页脚任何位置都算违规（校验器按子串匹配）。
#
# 默认留空。人名是私人的 —— 请填你自己团队的黑名单，或者临时用命令行追加：
#   node validate-ppt.mjs 项目/xxx/ppt/index.html --names=张三,李四
#
# 为什么要有这条规则：这份材料是要**直接发给第三方看**的。署名位置应该写角色
# （"创始人" "项目负责人" "数据来源 · 某机构"），一旦写进真名，材料就从
# "一份可对外分发的文档"变成了"某人的私人文件"，也会给当事人带来不必要的暴露。
#
# 示例格式（把下面这行换成你自己的，或直接删掉）：
# 张三
# 李四
